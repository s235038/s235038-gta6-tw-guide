# 玩家回饋表單範本

將以下文字貼到現有表單工具即可使用。站方發布前，把表單的自動收集電子郵件與登入限制關閉，確認可從未登入的手機送出。回覆由站方私下檢視，分享的摘要省略可識別玩家的資訊。

**表單標題**

G6 台灣攻略資料庫｜攻略回饋

**表單說明**

遇到版本資訊錯誤、遊戲卡點或網站操作問題，歡迎告訴我們。請填寫可重現的遊玩或操作情境。請勿填入真名、電子郵件、帳號、兌換碼或未公開的私人連結。

| 欄位 | 型態 | 是否必填 |
| --- | --- | --- |
| 想回報什麼 | 單選。攻略錯誤／想看新攻略／搜尋收藏等操作問題／其他 | 必填 |
| 哪一篇文章或哪個頁面 | 短答。貼公開站內網址，或寫頁面標題 | 選填 |
| 遊戲平台或瀏覽裝置 | 短答。遊戲可填 PS5、Xbox Series X、Xbox Series S；網站可填 iPhone Safari、Android Chrome 或電腦瀏覽器 | 選填 |
| 你遇到什麼問題 | 段落。寫章節、遊戲版本、目前進度、看到的提示或網站操作順序 | 必填 |
| 你預期看到什麼 | 段落。寫下一步提示、想找的資料或網站應有結果 | 選填 |
| 是否可能包含劇透 | 單選。有／沒有／不確定 | 必填 |
| 可公開核對的證據網址 | 短答。貼官方或具名實測頁 | 選填 |

**送出後訊息**

收到，感謝你提供線索。站方會先核對來源及重現條件，有足夠證據後才會更新攻略。
